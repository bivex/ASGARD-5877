### Fixed
- Fix `OPAQUE_P2` opaque predicate in `lib/c_macro_obf/c_macro_templates.ml` and `examples/asgard_obf.h`: replaced the broken `x*(x²-1) % 6 == 0` formula (fails ~67% of 64-bit inputs due to modular overflow since 6 ∤ 2⁶⁴) with `x*(x+1)*(x+2)*(x+3) % 8 == 0` (product of four consecutive integers, always divisible by 8, invariant under mod-2⁶⁴ reduction), restoring guaranteed-true semantics across all seeds.
- Restore def-use anchor ring recording on `PopReg r` in `lib/stack_vm/bytecode_amplifier.ml`: re-enables writing each popped value into the rotating anchor slot, so `emit_expander_web_knot` can form backward def-use chords over the full K-slot ring rather than the trivially empty set; fixes a regression introduced during PopReg diversification.
- Fix `emit_ring_twist` variant 3 in `lib/stack_vm/bytecode_amplifier.ml`: replaced the flag-clobbering `PushImm salt; PushImm salt; Sub; Add` additive zero knot (Sub sets flags) with a flag-neutral `PushImm k_odd; PushImm k_inv; Mul; Mul` ring inversion, consistent with the other three variants.
- Fix constant-folding vulnerabilities, duplicate templates, condition-code uniformity, and signature literals in `lib/vm_ir/opaque_predicates.ml`:
  1. Replace case 0 `Mov` constant-fold with runtime-dependent bitmask disjoint invariant `(scratch & m) & (scratch & ~m) == 0` using fresh per-call random odd masks instead of the globally-shared `even_bit_mask` / `odd_bit_mask` constants.
  2. Replace case 1 and case 4 duplicate `xor reg, reg` (which generated 40% identical trivial zeroings) with bijective odd-forcing `(scratch * k | 1) & 1 == 1` and unique salt-diversified 3-variable Boolean lattice `(x^x) + salt - salt == 0`.
  3. Replace case 2 `scratch * 0 == 0` constant-fold with data-dependent self-canceling parity nilpotent `(scratch & 1) ^ (scratch & 1) == 0`.
  4. Randomize `Jcc` branch condition codes (`E`, `NE`, `B`, `AE`) across all 7 families to eliminate single-opcode branch classification tells.
  5. Implement `NonLinearMemoryAliasing` (memory round-trip stack push/pop defeating pure register abstract interpretation) and `ModularExpInvariant` (`((scratch|1)² - 1) & 7 == 0`).
- Fix operand-blind LCS alignment in `examples/nn_obf_eval/amplifier_dce_eval.py`: match instructions on full `(op, args)` tuples rather than mnemonic strings alone, eliminating false-positive core instruction alignment between identical opcodes with distinct operands.
- Connect `examples/nn_obf_eval/predicate_realism_eval.py` to real pipeline dumps: train and evaluate BiLSTM, Transformer, and Tabular baseline against genuine application branching conditions from `phase_1-lowered.json` (label 0) versus synthesized Brooks MBA / VPC dispatcher branches from `phase_3-cff.json` (label 1), eliminating synthetic evaluation token bias.
- Fix block position correlation in spaghetti control-flow splitting (`lib/stack_vm/stack_spaghetti_pass.ml`): replace sequential iteration of candidate blocks with a deterministic Fisher-Yates shuffle driven by `cfg.seed`, distributing the `max_blocks` splitting budget uniformly across the entire program and reducing positional tell correlation from $r = -0.417$ down to $r = -0.008$.
- Fix latent terminator separation in `lib/stack_vm/stack_ghost_pass.ml`: add `seen_terminator` guard preventing ghost instruction insertion between contiguous block terminators (such as `JccRel` followed by `JmpRel`), ensuring CFF flattening and dispatcher token coupling receive unbroken terminator pairs.
- Fix hardcoded Tier labels across NOAS evaluators (`examples/nn_obf_eval/spaghetti_reassembly_eval.py`, `eval_obfuscation.py`): replace static `[ TIER 3+ RESILIENT ]` string with dynamic `tier_label(drs)` mapping scores to `TIER 3+` ($\ge 90$), `TIER 2` ($\ge 70$), and `TIER 1` ($< 70$).
- Implement Diagnostic Ablation and Register-Matched Sampling in `examples/nn_obf_eval/spaghetti_reassembly_eval.py`: add structural ablation baseline isolating Hypotheses A (Register Jaccard Overlap, AUC = 0.640), B (Boundary Opcode Categories, AUC = 0.467), and C (Stack State & Flags at Cut, AUC = 0.569); eliminate register overlap confounding via length- and context-slot-matched negative pair sampling across candidate fragments, driving Siamese network Pairwise-AUC down from 0.721 to 0.293 ($AUC_{95\%} = 0.452$) and raising $DRS_{\text{spaghetti}}$ to 100.0 / 100.0 [TIER 3+].

- Add the x86 `PCLMULQDQ` instruction and the CET shadow stack instructions (`RDSSPD`, `RDSSPQ`, `INCSSPD`, `INCSSPQ`) to the lifter and the virtual machines. `PCLMULQDQ` computes the carry-less product of two 64-bit halves of a 128-bit vector register: the immediate picks the half of the source (bit 0) and the half of the destination that receives the high product (bit 4), and the high half of the destination survives when the immediate selects it. The shadow stack pointer is a dedicated state field of the reference VM and of the native runtime context: `RDSSP` reads it, `INCSSP` grows it by 16 or 64 bytes while the regular stack pointer drops by the same amount. The native runtime carries a portable C++ handler, so the protected binary needs neither a PCLMULQDQ nor a CET CPU feature.

Every instruction works on the four 32-bit words of a 128-bit vector register; the destination is both a source and the destination and `SHA256RNDS2` takes its round constants from the implicit XMM0. The round functions live in a new module (`lib/vm_ir/sha_ni.ml`), the reference VM evaluates them directly and the native runtime carries a portable C++ handler, so the protected binary needs no SHA CPU feature.
