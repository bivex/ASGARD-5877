# Threat Analysis: Shared-Direction Reuse and Lattice Recovery (arXiv:2608.26651)

Analysis of the shared-mask leakage primitive described in *"Beyond Vector Hiding: Breaking and Mitigating Shared-Direction Weight Obfuscation in TEE-Offloaded Large Language Models"* (Zhang et al., arXiv:2608.26651, 2026-08-27), and its transfer to the ASGARD-5877 protection engine.

The paper's domain is on-device LLM weight obfuscation under a Trusted Execution Environment (TEE), not binary protection. It is included here because the *structural* primitive it isolates — a single secret reused across many sites — is domain-independent and applies directly to the masking layers of this repository.

---

## 1. Executive Summary

The paper's contribution is a negative result: **changing the arithmetic representation of an obfuscation does not remove its leakage if the underlying structure is unchanged.**

- ArrowCloak protects each weight row by injecting a scalar multiple of one shared secret direction. The injected mask $rk^{\top}$ has rank one.
- Over the reals, the shared direction is spectrally dominant. The proposed **SpectralLeak** attack estimates it and projects it away, recovering a high-accuracy surrogate model.
- ArrowCloak's published modular formulation computes everything modulo a prime $Q = 2^{31}-1$. Field-wide modular arithmetic destroys the Euclidean geometry that SpectralLeak depends on, and **defeats** that attack.
- However, the mod-$Q$ realization still satisfies the same algebraic identity. A second attack, **LatticeLeak**, exploits the residual relation: combinations of exposed rows that cancel the shared mask, recovered through lattice reduction (LLL) over a public Construction-A lattice.
- LatticeLeak reconstructs every protected fixed-point parameter of a BERT-Base victim exactly (72 tensors, 82,944 rows, 84,934,656 coordinates) in 233.44 seconds, with no victim queries, no labels, and no fine-tuning.
- The defense, **ButterflyCloak**, removes the primitive rather than the symptom: a keyed full-rank butterfly mask whose trusted correction cost is $O(\ell \max\{m,d\} \log d)$ instead of $O(\ell(m+d))$ for rank-one masking.

The transferable rule for this repository:

> Reusing one secret across $N$ sites creates a public, testable cancellation relation. Modulo arithmetic hides the *spectral manifestation* of that relation, never the relation itself.

## 2. Protected Setting

### 2.1 Baseline Scheme

The accelerator observes

$$
Y = P(D + rk^{\top}) W \bmod Q,
$$

where:

| Symbol | Meaning |
|---|---|
| $W$ | Victim weight matrix (fixed-point encoded) |
| $D$ | Diagonal matrix of row-wise scales |
| $P$ | Secret row permutation |
| $rk^{\top}$ | Reused rank-one mask, identical direction in every row |
| $Q = 2^{31}-1$ | Prime modulus, field-wide arithmetic |

Encoding uses fixed-point exponent $f = 16$, scale $s = 2^{16}$:

$$
W = \left\lfloor s \widehat{W} \right\rceil \bmod Q.
$$

Two coefficient settings are evaluated: the released implementation's small integer ranges mapped into $\mathbb{F}_Q$, and a defense-favorable setting with $r$, $k$, and the non-zero diagonal entries of $D$ sampled uniformly from $\mathbb{F}_Q$.

### 2.2 Consequence of Rank-One Reuse

Every exposed row is coupled through the same $rk^{\top}$ term. Writing the rows of one block $I$ of size $b$:

$$
Y_I = D_I W_{\pi(I)} + r_I v^{\top} \bmod Q.
$$

Any blockwise coefficient vector $c \in \mathbb{F}_Q^{b \times 1}$ satisfying $c^{\top} r_I = 0$ cancels the shared term:

$$
c^{\top} Y_I = \beta^{\top} W_{\pi(I)} \bmod Q, \qquad \beta = D_I c.
$$

This cancellation relation is the exploitable primitive. It is public-testable: it holds for any secret $r_I$, $D_I$, and $P$, and the attacker verifies it directly.

## 3. Attack 1: SpectralLeak (Real-Valued Arithmetic)

The shared direction dominates the row space, so a principal component of the exposed matrix recovers it. SpectralLeak estimates the shared component, removes it, and re-establishes the private-to-public row correspondence, after which the weights are recovered by projection.

Across 12 task settings the surrogate reaches 87.98% mean accuracy against 89.85% for the victims.

**Failure mode.** Field-wide mod-$Q$ arithmetic wraps every addition and multiplication. Mapping residues back to real values does not preserve the Euclidean geometry that makes the shared direction spectrally dominant, so the PC1 signal disappears and correspondence recovery drops to near-random levels. The paper states this explicitly: modular wrap removes the real-valued manifestation of rank-one reuse, but not the underlying relation.

## 4. Attack 2: LatticeLeak (Mod-$Q$ Arithmetic)

LatticeLeak targets the algebraic residue of the same reuse.

### 4.1 The Cancellation Lattice

For a block $I$, define $a_I = D_I^{-1} r_I$. The integer coefficient vectors that cancel the shared component form

$$
L_I = \left\{ \beta \in \mathbb{Z}^{b} \;:\; \beta^{\top} a_I = 0 \bmod Q \right\}.
$$

The map $\phi_I : \mathbb{Z}^{b} \to \mathbb{F}_Q$, $\phi_I(\beta) = \beta^{\top} a_I \bmod Q$ is surjective, so $L_I = \ker \phi_I$ is a full-rank integer lattice in $\mathbb{Z}^{b}$ with index and determinant $Q$. The cancellation space over $\mathbb{F}_Q$ has dimension $b-1$, but its integer preimage has rank $b$.

### 4.2 Short-Vector Scale

The Gaussian heuristic gives a characteristic short-vector scale of $Q^{1/b}$. With the paper's operating point $b = 8$ and $Q = 2^{31}-1$, this is approximately 14.7. Minkowski's theorem guarantees a nonzero vector with norm $O(\sqrt{b}\, Q^{1/b})$, but it does not guarantee $b$ independent short vectors in an LLL-reduced basis, so LLL outputs are treated as candidates and filtered by public consistency checks.

### 4.3 Public Construction-A Lattice

The attacker cannot build $L_I$ directly because $a_I$ is secret. Instead it selects a public coordinate set $T \subseteq [d]$ of size $t$, constructs the corresponding Construction-A lattice from the exposed values, and applies LLL. Each returned combination is then applied to all $d$ coordinates and retained only if it passes the public consistency checks.

Operating point: $b = 8$, $t = 24$, giving a 24-dimensional lattice instance independent of the full row width $d$. This point is used unchanged across architectures rather than tuned per model.

### 4.4 Span Recovery

$b$ independent accepted combinations recover the block's victim row span:

$$
S_I = \operatorname{span}_{\mathbb{Q}} \left\{ W_{\pi(i)} : i \in I \right\}.
$$

Only the $t$ selected coordinates determine the lattice instance, but the accepted coefficients recover the span over all $d$ victim coordinates.

### 4.5 Individual Row Recovery via Intersections

Let two blocks $I$ and $J$ share exactly one index $i$. If the victim rows over $I \cup J$ are linearly independent over $\mathbb{Q}$, then

$$
S_I \cap S_J = \operatorname{span}_{\mathbb{Q}} \left( W_{\pi(i)} \right).
$$

A vector in the intersection has one expansion over $I$ and another over $J$; subtracting the expansions produces a dependence over $I \cup J$, and linear independence forces every coefficient outside $I \cap J = \{i\}$ to vanish. The attack checks that the intersection is one-dimensional and rejects the candidate otherwise.

Because $W$ uses integer fixed-point encoding, exact rational intersection returns a projective integer row. Dividing by the coordinate gcd yields its primitive representative, which equals the victim row up to sign provided the encoded row is primitive. Non-primitive rows leave an absolute integer scale ambiguity, so exact-recovery claims are restricted to checkpoints that pass the primitive-row audit.

### 4.6 Block Schedule

Required overlaps are produced with a grid schedule. For block size $b$, place $b^{2}$ exposed rows in a $b \times b$ grid and recover the spans of its $b$ row blocks and $b$ column blocks. Each cell belongs to exactly one row block and one column block, so their intersection isolates the victim row at that cell.

| Quantity | Value |
|---|---|
| LLL reductions per group of 64 rows | 16 |
| Span intersections per group of 64 rows | 64 |
| Reductions for a 768-row matrix | 192 |
| Reductions for a 3072-row matrix | 768 |
| Lattice instance dimension | 24 (independent of row width $d$) |

### 4.7 Validation Without an Oracle

Recovery is validated without any victim prediction oracle:

1. Each horizontal/vertical span pair must have a one-dimensional intersection.
2. Coefficient relations learned from the selected coordinates must remain consistent over every accelerator-visible coordinate.

If either check fails, the attacker discards the coordinate window and retries with a disjoint one. No victim row, secret coefficient, permutation, task label, or victim output is used. Algebraic recovery yields an unordered set of signed primitive rows; a public ancestor, when available, is used only afterwards for global one-to-one cosine assignment to fix signs and semantic positions.

### 4.8 Scope

LatticeLeak is not a general polynomial-time algorithm for arbitrary hidden-lattice problems. It depends on the codimension-one cancellation relation created by rank-one reuse, which decomposes full-model recovery into fixed-size lattice instances. Exact encoded-row recovery additionally requires short-vector separation, independence of the overlapping row spans, and a known integer scale.

## 6. Defense: ButterflyCloak

### 6.1 Removing the Primitive

SpectralLeak and LatticeLeak operate in different arithmetic domains but succeed for the same reason: ArrowCloak reuses one mask direction across every protected row. Replacing the rank-one mask with a rank-$\rho$ mask only expands the leaked component into a $\rho$-dimensional principal subspace; in the paper's rank-2 and rank-3 ablations, projecting out the first two or three principal components restores the private-to-public row correspondence. A small constant $\rho$ therefore delays adaptive PCA instead of eliminating the primitive.

Resistance to subspace removal requires the mask rank to scale with $n$. A generic full-rank mask provides this but costs $O(n^{2}\ell)$ trusted correction, which removes the benefit of offloading.

### 6.2 Keyed Maximal-Rank Butterfly Mask

ButterflyCloak samples an invertible diagonal matrix $D$, a row permutation $P$, a mask strength $\alpha$, and a keyed mask $M_{\theta}$:

$$
Y = P(DW + \alpha M_{\theta}),
$$

with the guarantee

$$
\operatorname{rank}(M_{\theta}) = \min(m, d).
$$

For a square layer $M_{\theta} = S Z_{\theta}$, where $S$ is a keyed sign diagonal and $Z_{\theta}$ is a product of $L = \lceil \log_2 d \rceil$ sparse butterfly stages. Each stage pairs coordinates and applies independent invertible $2 \times 2$ rotations; every stage is full rank, so their product is full rank. Rows of $M_{\theta}$ are not scalar multiples of one reused direction.

### 6.3 Trusted Correction Cost

With accelerator output $O_{\mathrm{obf}} = X Y^{\top}$, the TEE recovers

$$
XW^{\top} = \left( O_{\mathrm{obf}} P - \alpha X M_{\theta}^{\top} \right) D^{-1}.
$$

Materializing $M_{\theta}$ densely would cost $O(\ell md)$, so the keyed butterfly stages are applied directly; each stage contains disjoint $2 \times 2$ operations and costs linear work in its width.

| Correction mask | Mask rank | TEE work |
|---|---|---|
| Shared direction (ArrowCloak) | $1$ | $O(\ell(m+d))$ |
| Butterfly mask (ButterflyCloak) | $\min(m,d)$ | $O(\ell \max\{m,d\} \log d)$ |
| Independent dense mask | $\min(m,d)$ | $O(\ell md)$ |

### 6.4 Measured Defense Effect

With independent tensor keys and mask strength $512\times$ the median victim-row norm, full-model BERT protection preserves the victim's 91.6284% accuracy while reducing PC1 energy to 0.13049% and raw correspondence recovery to 0.11695%. The transferred LatticeLeak implementation recovers none of the 82,944 victim rows.

## 7. Transfer to ASGARD-5877

### 7.1 The Analogous Primitive

The paper's finding is about weights, but the mechanism is about *key reuse*. ASGARD-5877 reuses secrets across sites in several places, and each such site is a candidate for the same structural weakness:

| Site | Reused secret | Consequence if shared |
|---|---|---|
| `lib/mba_engine` | Verified MBA identity sets and mask constants applied to many blocks | A single linear combination of masked blocks may cancel the shared term and expose the identity space |
| `lib/mba_engine/egraph.ml` | Equality-expansion rewrite rules over a shared pool of verified identities | Correlated rewrite structure across all expanded expressions |
| `lib/cff` | Shared dispatcher, handler table, and opaque-predicate scheme | One cancellation relation across the whole flattened CFG, matching the rank-one analog |
| `lib/native_vm`, `lib/stack_vm`, `lib/multi_vm` | Shared VM handler set and bytecode layout conventions | Same-direction mask analog: the handler table is a rank-one-like common component of every protected block |
| `lib/tech_2601`, `lib/tech_2603`, `lib/tech_2608` | Per-build masking and anti-analysis material | Already designed against reuse; the lattice test below is the missing validation |

### 7.2 Why the Modulo Argument Applies Here

The paper's central observation transfers directly: ASGARD-5877 already computes MBA semantics in $\mathbb{Z}_{2^{64}}$ and encodes bytecode under wrapping arithmetic. Under such arithmetic the *spectral* manifestation of a shared direction is already suppressed — a PCA over wrapped values does not expose a dominant common component the way it does over the reals. The shared relation nevertheless survives as an algebraic identity, exactly as in the mod-$Q$ realization.

Therefore the correct threat model for this repository is LatticeLeak's model, not SpectralLeak's.

### 7.3 The Modulus Caveat: $\mathbb{Z}_{2^{64}}$ Is Not a Field

This is the sharpest difference between the paper and this codebase.

LatticeLeak's construction requires a **prime** modulus: $Q = 2^{31}-1$ is prime, so $\mathbb{F}_Q$ is a field, the map $\phi_I$ is surjective, and $L_I$ has index exactly $Q$. The MBA semantics of ASGARD-5877 live in $\mathbb{Z}_{2^{64}}$, which is a ring with zero divisors, not a field:

- $2^{64} = 0$ in the ring, so there is no field inversion and no surjective homomorphism onto $\mathbb{F}_{2^{64}}$.
- The cancellation relation $c^{\top} r_I \equiv 0 \bmod 2^{64}$ is now a sublattice whose index is $2^{\nu}$, where $\nu = v_2(r_I)$ is the 2-adic valuation of the shared coefficient, not $2^{64}$ itself.
- If the shared coefficient is even, the cancellation space is larger than in the prime case and short-vector separation degrades; if the shared coefficient is odd, the cancellation space has full index and the prime-case intuition carries over most closely.
- Short-vector analysis must therefore be redone over the 2-adic structure rather than imported from $\mathbb{F}_Q$.

Consequences for any port of the attack:

1. Reduction modulo an odd prime $p > 2^{64}$ recovers a field setting, but the lift from $\mathbb{Z}_{2^{64}$ into $\mathbb{F}_p$ is not injective on the masked values, so recovered coefficients must be re-validated in the original ring.
2. A reduction that keeps the 2-adic structure is faithful but must account for the non-field cancellation space explicitly.
3. The correct engineering answer is to remove the shared component rather than to rely on the modulus: give every site an independent mask, so that no cancellation relation exists over any ring.

### 7.4 Defensive Design Rule

The transferable form of ButterflyCloak is not the butterfly network itself but the property it enforces:

> Every masking site must receive an independent, full-rank-varying mask, so that the family of protected blocks spans no common low-dimensional component and no linear combination of them cancels a shared term.

Concrete applications in this repository:

- **Per-site MBA masking.** When `Mba_engine` rewrites a block with an MBA identity, the identity's constants must be derived per site (keyed per block index) rather than drawn from one shared verified identity table. Reusing one table across all blocks is the rank-one analog.
- **Per-site CFF dispatcher material.** The dispatcher key, the opaque-predicate digest, and the handler table must be re-keyed per function, not per build.
- **Per-site VM handler masks.** In `lib/native_vm` and `lib/stack_vm`, the mask applied to a handler's code must vary per handler and per build; a single build-wide mask is the exact pattern the paper breaks.
- **Lattice probe as a regression test.** A negative test that (a) collects sibling blocks sharing one secret, (b) solves for a combination cancelling the shared term over the relevant ring, and (c) asserts that no short non-trivial solution exists, would fail today for any site that reuses a secret. This is the analogue of the paper's public consistency checks.

### 7.5 What Is Not Claimed

- The paper does not provide an attack on binary virtualization obfuscation. Its attacks target weight matrices with algebraic structure; the VM-Protector's protection surface is code, not weights.
- No variant of LatticeLeak has been demonstrated against ASGARD-5877. The transfer described here is a structural argument, and the required 2-adic lattice analysis has not been performed.
- The comparison to rank-one masks is a structural analogy (shared secret across many sites), not a claim that ASGARD-5877's masks are literally rank one.

## 8. Limitations and Caveats

| Limitation | Detail |
|---|---|
| Non-general algorithm | LatticeLeak works for the targeted models and parameter settings; it is not a general polynomial-time hidden-lattice solver |
| Dependence on reuse | The attack requires a codimension-one cancellation relation; per-site independent masking removes the primitive entirely |
| Scale ambiguity | Non-primitive encoded rows leave the absolute integer scale unresolved |
| Public ancestor needed for placement | Without a public model, the recovered rows cannot be placed into an executable model, though the projective row set is still returned |
| Prime modulus required | The published construction is over $\mathbb{F}_Q$ with $Q$ prime; the $\mathbb{Z}_{2^{64}}$ setting of this repository requires a separate 2-adic analysis |
| Domain | Evaluated on LLM weight matrices, not on native code or bytecode |
